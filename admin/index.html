مدیریت کاربران

زیرساخت فعلی Backend هنوز ثبت‌نام، حساب‌های چندکاربره، نقش‌های پنل وب و مدیریت اشتراک کاربران را ارائه نمی‌کند. این بخش پس از پیاده‌سازی احراز هویت و API چندکاربره فعال خواهد شد؛ هیچ داده ساختگی نمایش داده نمی‌شود.

اتصال به Backend مالک

توکن فقط تا زمان Refresh یا بستن تب در حافظه نگهداری می‌شود. آن را روی دستگاه عمومی وارد نکن. برای دامنه این سایت باید CORS در Backend فعال باشد.
