اتصال به Backend
توکن فقط در حافظه این صفحه قرار می‌گیرد و با Refresh پاک می‌شود. برای درخواست‌های مرورگر، Backend باید CORS همین دامنه را مجاز کرده باشد.
وضعیت و محدودیت‌های امنیتی
توکن‌های Provider در Backend رمزنگاری می‌شوند.
کلیدهای خارجی Railway و GitHub و Cloudflare باید در Secret Variables باشند.
توکن ADMIN به کاربران عمومی داده نشود.
برای چندکاربره شدن: Auth، session، tenant isolation و rate limiting لازم است.
